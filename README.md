# AutoBrush31

Android AccessibilityService assistant for automating the user's own installed game flow.

Target package: `com.hortor.mwdl.gf`

This project uses Android AccessibilityService screenshots and gestures; it does not modify the game APK or require root.

The current prototype automates entering 源初秘境 → 地狱31 → 进入秘境 and uses mini-map image processing for navigation. Boss/clear recognition remains a calibration item.
